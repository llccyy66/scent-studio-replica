# Perfume Page Perfect

我将做一个香水网站，给你发一张图片，这是我们前端设计师设计出来的。你看一看还有没有可以优化的地方。

我认为你基本按照这个去复刻就行了。核心要求是必须 1:1 复刻，最好完全按照这个来，或者你也可以再加入一下你的理解。就做这一个页面就行了。原生 HTML + CSS + JavaScript，零框架
