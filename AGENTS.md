## Application rules
- Keep the required TanStack Start routing shell; implement the perfume page with native CSS and minimal React state because the preview runtime requires React.
- Use the uploaded design's cropped product photograph through an asset pointer, with real HTML text and SVG radar graphics for the rest of the page; this preserves fidelity without flattening the page into an image.
- Define perfume styling centrally in src/styles.css and use perfume Button variants for interactions, so the design remains consistent.
